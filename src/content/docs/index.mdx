# Jawi Digital Book
# 📚 หนังสือแห่งปัญญา อักษรยาวี
## คำนำ / บทเริ่มต้น

สลามแบ เราต้อนรับแบเข้าสู่โลกของหนังสือดิจิทัลภาษามลายูอักษรยาวี (Jawi) หนังสือเล่มนี้ถูกสร้างขึ้นด้วยเทคโนโลยี SSG เพื่อนำเสนอคลังความรู้โบราณในรูปแบบที่เข้าถึงง่าย รวดเร็ว และเป็นระบบ

เนื้อหาทั้งหมดถูกรวบรวมและจัดระเบียบอย่างพิถีพิถัน เพื่อให้แบสามารถศึกษาภาษา วัฒนธรรม และภูมิปัญญาของมลายูอักษรยาวีได้อย่างลึกซึ้ง

### ต้นฉบับอักษรยาวี (Teks Jawi)
<div class="jawi-text" dir="rtl" lang="ms-Arab">
  كتاب ديجيتل جاوي ايڠ دتوليس دڠن كمس دان جلس، اونتوق مڠاجر کان ڤڽاڠن دان بوڠا.
</div>

### คำปริวรรตและคำอธิบาย (Transliterasi & Huraian)
*   **คำอ่านรูมี:** Kitab digital Jawi yang ditulis dengan kemas dan jelas, untuk mengajar keindahan dan bunga.
*   **คำอธิบาย / ศัพท์สำคัญ:**
    *   **Jawi:** อักษรที่ใช้เขียนภาษามลายูในอดีต ซึ่งใช้ตัวอักษรอาหรับเป็นฐาน
    *   **SSG:** Static Site Generation หมายถึงการที่เว็บถูกเรนเดอร์ทั้งหมดล่วงหน้า ทำให้โหลดรวดเร็ว
